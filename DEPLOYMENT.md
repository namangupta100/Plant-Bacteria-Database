# Deployment Guide for Render

## Quick Setup

### 1. Prerequisites
- GitHub account with this repository pushed
- Render account (free tier works)
- PostgreSQL database already configured on Render

### 2. Deployment Steps

#### Option A: Using render.yaml (Recommended)
1. Push your code to GitHub
2. Go to [Render Dashboard](https://dashboard.render.com/)
3. Click "New" → "Blueprint"
4. Connect your GitHub repository
5. Render will automatically detect `render.yaml` and set up:
   - Web service (Django app)
   - PostgreSQL database connection
   - Environment variables

#### Option B: Manual Setup
1. **Create Web Service:**
   - Go to Render Dashboard
   - Click "New" → "Web Service"
   - Connect your GitHub repo
   - Configure:
     - **Build Command:** `./build.sh`
     - **Start Command:** `gunicorn build.wsgi:application`
     - **Environment:** Python 3

2. **Set Environment Variables** in Render:
   ```
   SECRET_KEY=<generate-a-secure-random-key>
   DEBUG=False
   DATABASE_URL=<your-postgres-connection-string>
   ALLOWED_HOSTS=.onrender.com
   PYTHON_VERSION=3.10.0
   ```

3. **Connect Database:**

### 3. Post-Deployment

After deployment completes:

1. **Create Superuser** (via Render Shell):
   ```bash
   python manage.py createsuperuser
   ```

2. **Access your app:**
   - Main site: `https://your-app-name.onrender.com`
   - Admin panel: `https://your-app-name.onrender.com/admin`

### 4. Environment Variables Reference

| Variable | Description | Example |
|----------|-------------|---------|
| `SECRET_KEY` | Django secret key (generate random 50+ chars) | Auto-generated by Render |
| `DEBUG` | Debug mode (False in production) | `False` |
| `DATABASE_URL` | PostgreSQL connection string | Auto-set from database |
| `ALLOWED_HOSTS` | Allowed hostnames | `.onrender.com` |
| `PYTHON_VERSION` | Python version to use | `3.10.0` |

### 5. Troubleshooting

**Static files not loading:**
- Check that `build.sh` ran `collectstatic`
- Verify `STATIC_ROOT` is set correctly
- Check whitenoise middleware is in `MIDDLEWARE`

**Database connection errors:**
- Verify `DATABASE_URL` is correctly set
- Check database is in the same region
- Ensure database user has proper permissions

**Application crashes:**
- Check Render logs: Dashboard → Your Service → Logs
- Verify all required packages in `requirements.txt`
- Check `ALLOWED_HOSTS` includes your Render domain

### 6. Local Development

To run locally:

```powershell
# Create virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Create superuser
python manage.py createsuperuser

# Run development server
python manage.py runserver
```

The `.env` file will be loaded automatically for local development.

### 7. Updating Deployment

To update your deployed app:
1. Push changes to GitHub
2. Render will automatically rebuild and redeploy
3. Check deployment logs for any errors

## Security Notes

- ⚠️ Never commit `.env` file to Git
- ✅ Use strong, random `SECRET_KEY` in production
- ✅ Keep `DEBUG=False` in production
- ✅ Regularly update dependencies for security patches
