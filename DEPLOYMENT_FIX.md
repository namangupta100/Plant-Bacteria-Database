# Quick Fix for Deployment Errors

## Issues Fixed

### 1. ✅ ALLOWED_HOSTS Error
**Error:** `DisallowedHost: Invalid HTTP_HOST header: 'plant-bacteria-database-xcns.onrender.com'`

**Solution:**
- Updated `build/settings.py` to properly handle `.onrender.com` wildcard
- The settings now correctly parse and apply the wildcard pattern

### 2. ✅ Missing coreapi Package
**Error:** `AssertionError: 'coreapi' must be installed for schema support.`

**Solution:**
- Added `coreapi==2.3.3`, `coreschema==0.0.4`, and `pyyaml==6.0.2` to `requirements.txt`
- These are required for Django REST Framework documentation

## Files Changed

1. **requirements.txt** - Added REST framework dependencies
2. **build/settings.py** - Improved ALLOWED_HOSTS parsing
3. **.env** - Corrected ALLOWED_HOSTS value

## If Issues Persist

Check Render logs for:
```bash
# In Render dashboard, go to:
# Your Service → Logs → Latest deployment
```

Common issues:
- **Database connection errors**: Verify DATABASE_URL is correct
- **Static files 404**: Run `python manage.py collectstatic` (included in build.sh)
- **Import errors**: Check all dependencies in requirements.txt
